تطبيق Barcode Shop — نسخة مشروع مع إعداد بناء APK عبر GitHub Actions

مهم: هذا ZIP ليس APK جاهزًا. يحتوي على إعداد آلي يجعل GitHub يبني APK في السحابة بعد رفع الملفات إلى مستودع GitHub.

الخطوات:
1. فك ضغط barcode-shop-android-source.zip على الكمبيوتر.
2. افتح GitHub وأنشئ مستودعًا جديدًا (New repository)، مثل barcode-shop. اجعله Private أو Public كما تفضّل.
3. داخل المستودع، اختر Add file > Upload files.
4. ارفع جميع محتويات المجلد الذي فككت ضغطه، بما في ذلك المجلد المخفي .github. إذا لم يظهر .github، تأكد أن مدير الملفات يعرض الملفات المخفية، أو أنشئ الملف يدويًا بهذا المسار: .github/workflows/build-apk.yml
5. اضغط Commit changes.
6. افتح تبويب Actions في المستودع. اختر "Build Android APK" ثم Run workflow إذا لم يبدأ البناء تلقائيًا.
7. انتظر انتهاء البناء وظهور علامة نجاح خضراء.
8. افتح تشغيل الـ workflow الناجح، وانزل إلى Artifacts، ثم حمّل barcode-shop-apk.zip.
9. فك ضغط artifact وستجد app-release.apk. انقله إلى هاتف Android وثبّته. قد يطلب Android السماح بالتثبيت من هذا المصدر.

ملاحظات:
- GitHub Actions يبني التطبيق على خوادم GitHub، فلا تحتاج إلى تثبيت Android Studio محليًا.
- البناء الأول قد يفشل بسبب توافق الإصدارات أو تغييرات خدمة البناء؛ إذا حدث ذلك، افتح سجل البناء وأرسل آخر جزء من الخطأ.
- التطبيق يحفظ المنتجات محليًا على الهاتف. احرص على عدم حذف التطبيق قبل توفير طريقة نسخ احتياطي.
- لا تشارك بيانات اعتماد GitHub أو رموز الوصول الخاصة بك.
